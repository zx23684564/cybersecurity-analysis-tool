# Cybersecurity Analysis Tool

This is a simple cybersecurity tool created for my Technical Writing and Documentation assignment. It helps check system logs and basic firewall rules.

## Features
- Check system logs for failed login attempts
- Check basic firewall configuration rules

## Setup Instructions
1. Open Git Bash or your terminal.
2. Clone this repository to your computer:
   `git clone https://github.com/zx23684564/cybersecurity-analysis-tool.git`
3. Open the project folder:
   `cd cybersecurity-analysis-tool`
4. Make sure Python 3 is installed on your computer to run the scripts.

- Firewall rule validation: Added to development plan.
- Blocked ports check: Port 21 (FTP), Port 23 (Telnet), and Port 445 (SMB).
